Controls

Keyboard

  • ←↑→↓ move around
  • Enter select
  • Esc back / cancel
  • F1 terminal
  • Alt+Tab switch windows

Mouse & touch

  • Click or tap icons to open apps
  • Drag a title bar to move a window
  • Drag an edge or corner to resize
  • Double-click a title bar to maximize
  • Type in the terminal once the canvas is focused

In this build

  • The browser app is the Browser shortcut above
  • Web pages open in a real iframe above the canvas
  • Pages that refuse framing show the browser's own error
  • No JavaScript engine for in-OS pages; no raw TCP
  • Files live in memory until you reload
